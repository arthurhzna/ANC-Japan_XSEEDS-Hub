# 1. Menyatakan Pengandaian ～たら

## POLA

**Kata kerja, kata sifat, kata benda bentuk ～た形 ＋ ら**

> ～た形 ＋ ら
> = kalau / jika / ketika ...

---

## GOLONGAN 1 → 五段動詞（ごだんどうし）

| Akhiran | Bentuk Kamus  | Bentuk ～た  |
| ------- | ------------- | ---------- |
| ～う      | かう（beli）      | ～った → かった  |
| ～つ      | たつ（berdiri）   | ～った → たった  |
| ～る      | かえる（pulang）   | ～った → かえった |
| ～ぶ      | よぶ（panggil）   | ～んだ → よんだ  |
| ～ぬ      | しぬ（mati）      | ～んだ → しんだ  |
| ～む      | よむ（baca）      | ～んだ → よんだ  |
| ～く      | かく（tulis）     | ～いた → かいた  |
| ～ぐ      | およぐ（berenang） | ～いだ → およいだ |
| ～す      | はなす（bicara）   | ～した → はなした |

### Contoh

> 買う → 買った → 買ったら
> かう → かった → かったら
> kau → katta → kattara
> = membeli → sudah membeli → kalau membeli

---

## GOLONGAN 2 → 一段動詞（いちだんどうし）

| Akhiran | Bentuk Kamus | Bentuk ～た |
| ------- | ------------ | --------- |
| ～える     | 食べる（makan）   | ～た → 食べた  |
|         | 出る（keluar）   | ～た → 出た   |
| ～いる     | 起きる（bangun）  | ～た → 起きた  |
|         | 見る（melihat）  | ～た → 見た   |

### Contoh

> 食べる → 食べた → 食べたら
> たべる → たべた → たべたら
> taberu → tabeta → tabetara
> = makan → sudah makan → kalau makan

---

## GOLONGAN 3 → 不規則動詞（ふきそくどうし）

| Bentuk Kamus  | Bentuk ～た |
| ------------- | --------- |
| くる（datang）    | ～た → きた   |
| する（melakukan） | ～た → した   |

### Contoh

> する → した → したら
> suru → shita → shitara
> = melakukan → sudah melakukan → kalau melakukan

---

# KATA SIFAT DAN KATA BENDA

| Jenis | Contoh | Bentuk ～た | Bentuk ～たら |
| ----- | ------ | --------- | ---------- |
| い形容詞  | 安い     | 安かった      | 安かったら      |
|       | 強い     | 強かった      | 強かったら      |
| な形容詞  | 暇      | 暇だった      | 暇だったら      |
|       | 元気     | 元気だった     | 元気だったら     |
| 名詞    | 雨      | 雨だった      | 雨だったら      |
|       | 休み     | 休みだった     | 休みだったら     |

### Rumus

**い形容詞**

> ～い → ～かった → ～かったら

Contoh:

> 安い → 安かった → 安かったら
> yasui → yasukatta → yasukattara
> = murah → kalau murah

**な形容詞**

> ～な → ～だった → ～だったら

Contoh:

> 暇 → 暇だった → 暇だったら
> hima → hima datta → hima dattara
> = senggang → kalau senggang

**名詞**

> 名詞 ＋ だった → 名詞 ＋ だったら

Contoh:

> 雨 → 雨だった → 雨だったら
> ame → ame datta → ame dattara
> = hujan → kalau hujan

# 注意！

Pola **～たら** dapat digunakan untuk beberapa kondisi berikut.

## 1. Pengandaian yang belum pasti terjadi

> いちおくえんが あったら、にほんに ひっこしたいです。

> ichioku-en ga attara, Nihon ni hikkoshitai desu.

> (+ kalau punya 100 juta yen, saya ingin pindah ke Jepang)

# 2. Menyatakan Bentuk “Meskipun” ～ても

## POLA

**Kata kerja, kata sifat, kata benda bentuk ～て形 ＋ も**

> ～て形 ＋ も
> = meskipun / walaupun ...

---

# Perubahan Bentuk

| Contoh | Bentuk ～て | Bentuk ～ても |
| ------ | --------- | ---------- |
| 飲む     | 飲んで       | 飲んでも       |
| 食べる    | 食べて       | 食べても       |
| する     | して        | しても        |
| 高い     | 高くて       | 高くても       |
| 安い     | 安くて       | 安くても       |
| 大変（な）  | 大変で       | 大変でも       |
| 暇（な）   | 暇で        | 暇でも        |

---

# Kata Kerja

### 飲む

> 飲む → 飲んで → 飲んでも

> nomu → nonde → nondemo

> = minum → meskipun minum

### 食べる

> 食べる → 食べて → 食べても

> taberu → tabete → tabetemo

> = makan → meskipun makan

### する

> する → して → しても

> suru → shite → shitemo

> = melakukan → meskipun melakukan

---

# い形容詞

### 高い

> 高い → 高くて → 高くても

> takai → takakute → takakutemo

> = mahal/tinggi → meskipun mahal/tinggi

### 安い

> 安い → 安くて → 安くても

> yasui → yasukute → yasukutemo

> = murah → meskipun murah

---

# な形容詞

### 大変

> 大変な → 大変で → 大変でも

> taihen na → taihen de → taihen demo

> = berat/sulit → meskipun berat/sulit

### 暇

> 暇な → 暇で → 暇でも

> hima na → hima de → hima demo

> = senggang → meskipun senggang

---

# ～なくても

Bentuk negatif juga dapat digunakan dengan **～ても**.

### Pola

> **～ない → ～なくても**

= meskipun tidak ～ / walaupun tidak ～

### Contoh

> お金がなくても、旅行に行きます。

> おかねが なくても、りょこうに いきます。

> okane ga nakutemo, ryokou ni ikimasu.

> (+ meskipun tidak punya uang, saya akan pergi berlibur)

---

# RINGKASAN

| Pola  | Fungsi                | Contoh        |
| ----- | --------------------- | ------------- |
| ～たら   | kalau / jika / ketika | 雨が降ったら、行きません。 |
| ～ても   | meskipun / walaupun   | 雨が降っても、行きます。  |
| ～なくても | meskipun tidak        | お金がなくても、行きます。 |

### Perbandingan

**～たら**

> 雨が降ったら、行きません。
> ame ga futtara, ikimasen.
> = **Kalau hujan, saya tidak pergi.**

**～ても**

> 雨が降っても、行きます。
> ame ga futtemo, ikimasu.
> = **Meskipun hujan, saya pergi.**
