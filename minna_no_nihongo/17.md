2. Menyatakan Perintah
～ないでください
POLA

Kata kerja ～ない + でください

Artinya:

Tolong jangan ...

Contoh

入る
→ はいらないでください。

Artinya: Tolong jangan masuk.

のる
→ のらないでください。

Artinya: Tolong jangan naik.

おす
→ おさないでください。

Artinya: Tolong jangan dorong/tekan.

えさをあげる
→ えさをあげないでください。

Artinya: Tolong jangan memberi makanan.

Contoh lain pada gambar:

お手を触れないでください。

Artinya:

Please do not touch.

起こさないでください。

Artinya:

Tolong jangan membangunkan.

3. Menyatakan Keharusan
～なければなりません
POLA

Kata kerja ～ない + ければなりません

Artinya:

Harus ...

Golongan 1

やすむ → やすまない

→ やすまなければなりません

はなす → はなさない

→ はなさなければなりません

Golongan 2

食べる → 食べない

→ 食べなければなりません

見る → 見ない

→ 見なければなりません

Golongan 3

くる → こない

→ こなければなりません

する → しない

→ しなければなりません

③ BAGIAN KANAN
練習しましょう！
マスクをつける

マスクをつけなければなりません。

Artinya:

Harus memakai masker.

勉強する

明日、しけんがありますから、勉強しなければなりません。

Artinya:

Karena besok ada ujian, harus belajar.

3. Menyatakan Bentuk “Tidak Perlu”
～なくてもいいです
POLA

Kata kerja ～ない + くてもいいです

Artinya:

Tidak perlu ... / tidak harus ...

Golongan 1

やすむ → やすまない

→ やすまなくてもいいです

はなす → はなさない

→ はなさなくてもいいです

Golongan 2

食べる → 食べない

→ 食べなくてもいいです

見る → 見ない

→ 見なくてもいいです

Golongan 3

くる → こない

→ こなくてもいいです

する → しない

→ しなくてもいいです

練習しましょう！
Contoh 1

Hari ini hari Minggu.

今日は日曜日ですから、早く起きなくてもいいです。

Artinya:

Karena hari ini hari Minggu, tidak perlu bangun pagi.

Contoh 2

Tidak suka sayuran.

やさいがきらいですから、食べなくてもいいです。

Artinya:

Karena tidak suka sayuran, tidak perlu makan.
