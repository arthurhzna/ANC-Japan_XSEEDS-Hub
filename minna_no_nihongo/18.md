# 2. MENYATAKAN KEMAMPUAN

## ～ことができます

### POLA

> **Kata kerja bentuk kamus ＋ ことができます**

### Bentuk negatif

> **Kata kerja bentuk kamus ＋ ことができません**

### Contoh

**ピアノをひく**  
→ ピアノをひくことができます。  
→ Bisa bermain piano.

**サッカーをする**  
→ サッカーをすることができます。  
→ Bisa bermain sepak bola.

**りょうりを作る**  
→ りょうりを作ることができます。  
→ Bisa memasak.

# BAGIAN TENGAH

## 3. MENGUBAH KATA KERJA MENJADI KATA BENDA

## ～こと

**こと** digunakan untuk mengubah aktivitas/kata kerja menjadi sesuatu yang berfungsi seperti kata benda.

### POLA

> **Kata kerja bentuk kamus ＋ こと**

### Menyatakan hobi — 趣味（しゅみ）

> **私のしゅみは ～ことです。**

Hobi saya adalah ....

### Contoh

**うたをうたう**  
→ うたをうたうことです。  
→ Bernyanyi.

**音楽をきく**  
→ 音楽をきくことです。  
→ Mendengarkan musik.

**しゃしんをとる**  
→ しゃしんをとることです。  
→ Memotret.

**えをかく**  
→ えをかくことです。  
→ Menggambar.

### Pertanyaan

**趣味は何ですか。**  
（しゅみは なんですか。）  
→ Apa hobimu?

# 4. 「SEBELUM」～まえに

## POLA

### Kata benda

> **Kata benda ＋ の ＋ まえに**

### Kata kerja

> **Kata kerja bentuk kamus ＋ まえに**

### Contoh — Kata kerja

**寝るまえに、顔をあらいます。**

→ Sebelum tidur, mencuci muka.

### Contoh — Kata benda

**食事のまえに、手を洗います。**

→ Sebelum makan, mencuci tangan.

### 注意！

Kalimat utama berada **sesudah ～まえに**.

### Struktur

> **[Aktivitas / waktu] + まえに、[kalimat utama]**

Contoh:

**寝るまえに、顔をあらいます。**

| Bagian | Fungsi |
|---|---|
| 寝るまえに | Sebelum tidur |
| 顔をあらいます | Mencuci muka |

# RINGKASAN 第18課

### ① Bentuk kamus — 辞書形

> 読みます → **読む**  
> 食べます → **食べる**  
> 来ます → **来る**  
> します → **する**

### ② Menyatakan kemampuan

> **V bentuk kamus + ことができます**

**日本語を話すことができます。**  
→ Bisa berbicara bahasa Jepang.

### ③ Mengubah aktivitas menjadi kata benda

> **V bentuk kamus + こと**

**音楽を聞くこと**  
→ Kegiatan mendengarkan musik.

### ④ Menyatakan “sebelum”

> **V bentuk kamus + まえに**

**寝るまえに、歯をみがきます。**  
→ Sebelum tidur, menggosok gigi.

> **N + の + まえに**

**食事のまえに、手を洗います。**  
→ Sebelum makan, mencuci tangan.
